# Silent Island Atlas

Live desk: **https://stakeaphobic-hue.github.io/silent-island-atlas/**

ST desk for Silent Island, the Shore, Narragansett Bay, and the roster.

- **Island** — painted chart, counties, MegaBlocks, BWC DA downtown Silent City. Connecticut and Long Island Sound shores with real harbors. Countess Island = The Gilded Grove.
- **Shore** — Bridgeport and East Fairfield, Waterbury, New Haven. BBC DP / BBC DVDA, BWC DV in Waterbury. Housatonic, Bridgeport Harbor, New Haven Harbor. Long Island’s north shore on the south edge.
- **Bay** — Narragansett Bay, east of the Sound. West Passage, East Passage, Sakonnet. Aquidneck, Conanicut, Prudence. Coastal facts, not courts.
- **Roster** — character lookup
