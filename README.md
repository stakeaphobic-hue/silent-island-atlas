- **City** — Silent City metro: BWC DA, south MegaBlock, Silent County gates, Route 69. Dashed pins are ST blanks (no street grid in the packet).
- **Bay** — Narragansett Bay coastal chart.
- **Estate** — first-person walk of the Phantasmagoric Estate gate axis (Slippery When Wet). Direct: [Estate](https://stakeaphobic-hue.github.io/silent-island-atlas/sww)
