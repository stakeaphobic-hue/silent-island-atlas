# Silent Island Atlas

ST desk for Silent Island, the Shore (East Fairfield · Waterbury · New Haven), and the roster.

- **Island** — painted chart, counties, MegaBlocks, BWC DA on the Gilded Shroud
- **Shore** — Bridgeport, the towns, BBC DP / BBC DVDA, BWC DV in Waterbury
- **Roster** — character lookup

Open `/` for the island, `/shore` for the municipalities, `/roster` for names.
